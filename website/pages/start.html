Welcome to ORS Explorer

Organisational Rule System Explorer makes it easy to build and expand a Wikibase knowledge graph from text. To get started, you can choose an ontology (in JSON format) that defines the concepts you want to extract. If you prefer, you can simply use the default ontology. If you already have a Wikibase knowledge graph, you can upload it and continue building on it.

Follow these steps to use the tool:

1 Configure (optional) Set an ontology that is used to define the concepts for the knowledge graph. You can also upload an existing knowledge graph to use as a starting point. If no knowledge graph is uploaded, ORS Explorer starts a new one.
2 Extract Provide a text from which to extract a knowledge graph fragment, based on the supplied ontology. Add one or several fragments to the knowledge graph.
3 Export Save the created knowledge graph in Wikidata format.
