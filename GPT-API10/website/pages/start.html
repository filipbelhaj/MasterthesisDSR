Quick Start

Welcome to TriExtract

TriExtract helps you build and expand a Wikibase knowledge graph from your data. To extract successfully, the server must already have ontology.json loaded, or you need to upload it below first. Uploading query.json is optional and only needed if you want to continue from an existing graph.

1 Required unless already loaded: upload a Wikibase ontology export.
2 Optional: upload an existing graph export if you want to continue a project.
3 Continue to the extraction workspace.
